# WhatsApp vs iMessage Explainer

An interactive one-page explainer for a non-technical audience. It follows the message "Hey, how are you?" through WhatsApp and iMessage, and shows what each server does and what it can see.

- Live page: https://shaunmessenger.github.io/whatsapp-vs-imessage/
- Open with iMessage selected: add `#imessage` to the end of the link.

## Files

- `index.html` is the whole site. Styles, icons and script are all inside it.

## Making changes

1. Edit `index.html`.
2. Commit and push to `main`. GitHub Pages rebuilds in about a minute.
